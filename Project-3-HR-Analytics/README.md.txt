# PeoplePulse – Employee Attrition & Workforce Intelligence

## Project Overview
PeoplePulse is a SQL-based HR analytics project that analyses employee attrition, workforce composition, attendance, performance, training, salary and retention risk.

## Project Objectives
- Calculate overall employee attrition and retention rates.
- Identify department-wise employee attrition.
- Analyse overtime, job satisfaction and work-life balance.
- Compare salary patterns across departments.
- Explore employee performance, training and promotion.
- Analyse attendance and absence patterns.
- Rank employees by salary.
- Create a rule-based employee retention risk classification.

## Tools & Technologies
- MySQL 8
- MySQL Workbench
- SQL
- CSV datasets

## Database Tables

| Table | Description |
|---|---|
| Employees | Employee details, salary, satisfaction and attrition |
| Departments | Department heads and locations |
| Attendance | Employee attendance and overtime hours |
| Performance | Performance scores, training and promotions |
| Salary_History | Salary and bonus details |

## SQL Concepts Used
- Database and table creation
- INSERT and SELECT statements
- Aggregate functions
- GROUP BY and ORDER BY
- CASE statements
- INNER JOIN
- Percentage calculations
- RANK() window function
- Rule-based classification

## Key Findings
- Total employees: 15
- Departments: 5
- Employees who left: 5
- Employees retained: 10
- Overall sample attrition rate: 33.33%
- Each department has 3 employees, including 1 employee marked as having left.
- 5 of the 8 employees marked for overtime have attrition marked Yes.

## Project Structure
- SQL – Complete SQL script
- Dataset – Five CSV datasets
- Documentation – Project report and presentation

## Limitations
- The dataset contains only 15 sample employees.
- Attendance data covers only one date.
- Salary history contains one annual snapshot.
- Attrition analysis is descriptive, not machine-learning prediction.
- Findings should not be generalized to a real organization.

## Conclusion
PeoplePulse demonstrates how SQL can transform HR data into useful workforce insights. It helps explore employee attrition, attendance, compensation and retention patterns.
