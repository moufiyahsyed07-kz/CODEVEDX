# Beyond Sales – Revenue Intelligence & Sales Performance Analysis

## Project Overview
This project analyzes e-commerce sales data using MySQL to identify revenue trends, customer purchasing patterns, product performance, payment collection issues, and inventory conditions.

The goal is to turn raw sales records into meaningful business insights that can support better decision-making.

## Objectives
- Analyze overall revenue and average order value.
- Identify top-performing customers and products.
- Compare revenue across cities and product categories.
- Track monthly revenue changes.
- Examine completed, pending, and failed payments.
- Identify repeat and one-time customers.
- Evaluate product inventory status.
- Discover high-value orders and sales patterns.

## Tools & Technologies
- MySQL 8.0
- MySQL Workbench
- SQL
- CSV datasets

## Database Tables
1. Customers
2. Products
3. Orders
4. Payments
5. Order_Items

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and aggregate functions
- INNER JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window functions (RANK, LAG)
- CASE statements

## Key Findings
- Total recorded revenue: ₹36,983.
- Total orders: 15.
- Average order value: ₹2,465.53.
- Chennai generated the highest city revenue.
- Electronics contributed the largest category revenue.
- Meera Nair was the highest-spending customer.
- Sunday recorded the highest sales revenue.
- 12 payments were completed, 2 were pending, and 1 failed.
- 5 customers were repeat buyers and 5 were one-time buyers.

## Project Structure
- SQL/ – SQL queries used for analysis.
- Dataset/ – CSV files containing the five database tables.

## Conclusion
This project demonstrates how SQL can be used to transform e-commerce transaction data into actionable business insights. The analysis highlights revenue performance, customer behavior, product contribution, payment collection, and inventory status.

**Note:** This project uses a sample dataset created for learning and analytical demonstration.
